# daily-budget — project memory

## Product philosophy
Базовый прогноз дневного бюджета при **минимальном вводе**. Сознательно НЕ
дневной трекер трат: пользователь просто вводит фактический остаток, когда хочет
обновить данные — прогноз `(остаток − фикс − сбережения) / дни` самокорректируется
на всё потраченное по факту. Rollover недотрат/перетрат происходит естественно
(остаток ÷ оставшиеся дни). Полноценный трекер — возможно в будущем, отдельная
функциональность.

## Future ideas (планы)
1. **Настраиваемый желаемый положительный остаток** — вынести захардкоженный
   green-буфер €200 в Settings, чтобы пользователь задавал свою «подушку» к концу
   месяца под собственный доход.
2. **Индикатор опережения в виджете** — показывать, насколько пользователь идёт с
   опережением/отставанием от плана (делает «тихую» экономию видимой, особенно
   когда до зарплаты далеко и равномерное размазывание прибавки незаметно).
3. **Один виджет по ситуации** — вместо трёх карточек (зелёный/жёлтый/синий)
   показывать ровно один, с цветом по состоянию:
   - приятный зелёно-синеватый — опережает буфер (>€200 к концу месяца);
   - зелёный — не залезает в копилку;
   - оранжевый — залезает в копилку;
   - красный — превышает все траты, включая копилку.
